SUMMARY
=======

Outcomes vs hypotheses (n = 8)

Hypothesis	Measure	Result
H1a — GDP explanation	Correct (8 participants)	7/8 correct (S07 partially correct, counted)
H1b — Recovery explanation	Correct economic domain	6/8 correct (S03 health misread; S06 trough confusion)
H1c — Primer dismissal	< 15 s primer time	3/8 dismissed (S03, S06, S07)
H1 link — Dismissed + wrong recovery	Of 3 dismissers, wrong recovery	2/3 (S03, S07) — S06 partial
H2 structured — Citation in Task 2	Specific value in Task 2	6/8 cited (S06 and S07 did not)
H2 open — Citation in 3a+3b fields	Specific value in open fields	3/8 did not cite (S06, S07, S08)
H3 structured — Correct 3d choice	Selected B	7/8 correct (S07 selected A)
H3 open — Non-causal in 3e	Non-causal open language	3/8 showed causal reversion (S03, S06, S07) + S05 mild, S08 mild
H4 — Source named in trust explanation	Named limitation or source	5/8 (S03, S06, S07 did not engage source panel)
H4 — Trust ≥ 4 without source engagement	Mismatch	2/8: S03 (trust 5, no source) and S06 (trust 5, no source)


Key Insights From Results

1. The Metric Primer works when read, but dismissal collapses its effect. S03 and S07 both got the recovery indicator wrong; both dismissed the primer in < 15 s. S01, S02, S04, S05 (all primer readers) got both indicators correct.

2. Evidence citation in structured tasks does not transfer to open fields. S08 cited −12.0 pp and −3.7 pp precisely in Task 2 but used impression-based language ("more significant economic shock") in Task 3. S06 and S07 did not cite in either.

3. Boundary selection (3d) ≠ boundary internalisation. S03 selected B correctly but used causal language in 3e. S06 selected B but gave strong causal language in 3e. Only S07 was consistent — and consistently wrong (selected A and gave causal language).

4. Sequential flow friction is real. S07 and S08 both independently named the multi-screen structure as a friction point. S07: "four screens are a lot." S08: "awkward to switch between Screen 2 and Screen 3."

5. Trust-correctness mismatch replicates. S03 (trust 5, preference 5, lowest metric accuracy) and S06 (trust 5, preference 5, no source engagement) both gave maximum trust and preference. S02 (highest accuracy) gave preference 3 — the lowest.

6. Economics/policy background consistently outperforms design/communication. S01, S02, S04, S05 (economics/policy): all correct on both metrics, all cited evidence in open fields, all correctly bounded in 3e. S03, S06, S07 (design/communication + comm): at least one major error on each task.


Invalidated or Weakened Assumptions (From Second Test Evidence)

- A6: "A separate primer screen ensures users understand indicators before comparing." → Invalidated. 3/8 dismissed it. Among dismissers, 2/3 got recovery wrong.
- A7: "A multiple-choice boundary task internalises the correlation-causation distinction." → Weakened. S03 and S06 selected B but reverted to causal in open question.
- A8: "Users who cite evidence in structured tasks will continue to cite in open fields." → Invalidated. S08 cited precisely in Task 2, did not in Task 3. S06 and S07 did not cite in either.
- A9: "Trust scores will reflect source engagement after method transparency is provided." → Weakened. S03 and S06 both gave trust 5 without opening the formula or reading Screen 4 carefully.


Remaining Unknowns

1. Would embedding the primer definition inline within Screen 2 (rather than on a separate screen) reduce dismissal without increasing cognitive load?
2. Would sentence-starter templates in the interpretation fields sustain evidence citation even for users with low familiarity?
3. Would a constructed-response boundary task (write your own claim, then self-evaluate) reduce causal reversion compared to the multiple-choice version?
4. Can the same interface serve both economics-background and design-background users effectively, or does the design need to more explicitly prioritise one group?
5. Would consolidating the four screens into a single progressive canvas reduce the flow friction noted by S07 and S08?
