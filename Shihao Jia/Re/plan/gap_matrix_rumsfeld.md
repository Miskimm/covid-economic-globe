# Map-the-Gap / Rumsfeld Matrix (Week 9 Reset)

## Known Knowns
- COVID health indicators and macroeconomic indicators can be sourced and displayed.
- Users report different preferences across prototype formats (dashboard, immersive, simulator, globe).
- Preference does not automatically equal comprehension quality.
- Tutor feedback confirms problem framing and user definition were previously weak.

## Known Unknowns
- Which format best supports **valid interpretation** (not just visual liking) for the primary user group?
- Which metric explanations users misunderstand most (for example, baseline comparison semantics)?
- Which trust/transparency cues most improve confidence calibration?

## Unknown Unknowns
- Whether guided narrative flow improves interpretation more than free exploration for novice users.
- Whether interaction complexity (3D movement, multi-panel controls) introduces hidden cognitive costs.
- Whether users over-attribute causality when seeing aligned health/economy trend lines.

## Assumptions to Validate
1. More interactive interfaces produce better understanding.
2. Showing more metrics increases analytical confidence.
3. Global overview and country detail can be understood equally well in one view.
4. Source transparency text is actually read and used in user judgment.

## Critical Gap Prioritization

### Gap A (Highest)
Users can operate the interface, but may not accurately interpret health-economy linkage.

### Gap B
Users may trust aesthetics over source/method transparency.

### Gap C
Users may prefer one format while learning better from another.

## Derived Research Questions (2-3, focused)

### RQ1 (Interpretation Validity)
How accurately can primary users explain the relationship between selected health and economic indicators across time and country comparisons?

### RQ2 (Format-Outcome Fit)
Which prototype interaction format produces the highest interpretation quality for primary users, independent of stated preference?

### RQ3 (Trust Calibration)
How do transparency cues (source state, method note, uncertainty framing) affect user trust and confidence accuracy?

## Output Metrics Mapped to RQs
- Interpretation correctness score (conceptual + applied comparison tasks).
- Preference vs comprehension divergence index.
- Trust score and confidence-reality alignment (self-confidence vs actual interpretation quality).
