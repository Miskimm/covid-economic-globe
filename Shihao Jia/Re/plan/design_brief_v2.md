# Design Brief v2 (Evidence-Synthesized)

## Project
DECO7180 — COVID-19 and Global Economic Impact

## Design Challenge
Help defined non-expert users interpret linked health-economic patterns across time and country comparisons with traceable evidence and transparent uncertainty boundaries.

## Evidence Inputs
- `feedback_audit.md` (tutor critique priorities)
- `problem_statement_v2.md` (user-specific problem framing)
- `gap_matrix_rumsfeld.md` (critical unknowns + RQs)
- `research_execution.md` (current mixed-method findings, n=4 survey baseline)

## Target Users (Locked for this cycle)

### Primary
Students in policy/design/economics-adjacent contexts who must justify pandemic-economy claims in coursework/presentations.

### Secondary
General informed public needing understandable country/time comparisons.

## Key Insights (Synthesis)
1. Current evidence indicates format preference variability, but preference alone is not a valid proxy for comprehension.
2. Interpretation quality and trust calibration are the highest-value gaps to reduce.
3. Users need explicit metric semantics, not only attractive visuals.
4. Transparency cues (source state, method note, uncertainty boundary) must be visible and testable.

## Design Requirements (Must-have)

### R1 Interpretation clarity
- Every core metric requires an inline plain-language explanation.
- Users must be able to perform before/after and cross-country comparison with evidence support.

### R2 Preference-understanding separation
- Evaluation flow must separately capture:
  - interface liking,
  - interpretation correctness,
  - confidence accuracy.

### R3 Trust transparency
- Interface must expose data source state and method limits at point-of-use.
- Users should be prompted to distinguish "observed pattern" vs "causal claim."

### R4 Cognitive load control
- Avoid dense multi-channel visuals that obscure meaning.
- Keep one primary analytical task per view.

### R5 Evidence traceability
- Each design choice must map to at least one research finding or tutor-identified failure point.

## Non-goals (This cycle)
- Predictive epidemiological modeling.
- Automated policy recommendation.
- Causal inference claims beyond dataset support.
- Feature-rich production build.

## Success Metrics (Cycle-end)
1. Interpretation correctness improves versus baseline tasks.
2. Users can articulate metric meaning without facilitator correction.
3. Trust ratings align better with source transparency awareness.
4. Analysis report clearly separates "liked" from "understood."

## Deliverables for Next Build/Test Cycle
1. Two low/mid-fidelity prototype options (max 2).
2. Task script focused on interpretation and trust.
3. Observation sheet with correctness + confidence fields.
4. Tutor-facing claim-evidence matrix.
