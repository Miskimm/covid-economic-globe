# Summary

## Pattern counts

| Pattern | Sessions | Count |
| --- | --- | ---: |
| Correctly identified UK as deeper economic shock | S01, S02, S04, S06, S07, S08, S09 | 7 |
| Baseline / percentage-point confusion | S03, S05, S07, S10 | 4 |
| Confused economic recovery with health recovery | S05, S07, S10 | 3 |
| False causation or weak causal boundary | S03, S05, S10 | 3 |
| Wanted clearer source/method traceability | S01, S02, S04, S06, S08, S09 | 6 |
| Preference/clarity did not equal understanding | S03, S05, S10 | 3 |

## Key insights

1. The country comparison task works as a first test because most users can identify the UK as having the deeper economic shock when they attend to the GDP values.
2. The largest comprehension risk is not the comparison itself, but the meaning of `pp`, `baseline`, and `trough`.
3. The label `Recovery vs 2020` remains ambiguous for lower-familiarity users because "recovery" can be read as health recovery.
4. Trust improves when limitations are visible, but higher-trust users still ask for exact formulas, original source links, and missing-data notes.
5. False causation remains a serious risk for lower-familiarity participants, especially when COVID cases and GDP drops are shown side by side.

## Invalidated or weakened assumptions

- Showing source names alone is not enough to support trust; users want method traceability.
- Users do not automatically distinguish economic recovery from health recovery.
- A visible correlation warning helps, but it does not fully prevent causal overclaiming.

## Remaining unknowns

- Whether adding inline glossary chips for `pp`, `baseline`, and `trough` would reduce misreadings.
- Whether the same users would perform better with a guided narrative flow than with static cards.
- Whether primary users from economics/policy courses remain more accurate with a larger real sample.

## Suggested next design direction

The next prototype should keep the three-card structure but add stronger interpretation scaffolding: glossary chips, example-based metric explanations, clearer "economic recovery" wording, and clickable source/method details.
