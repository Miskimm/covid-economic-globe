# Low-fi Wireframe Cards (Filled Mock Values)

## Shared setup
- T1 (2020) = initial shock period
- T2 (2023) = recovery stage
- Country A = United Kingdom
- Country B = Australia

---

## Screen 1 — Indicator Meaning

```text
+----------------------------------------------------------------------------------+
| COVID-19 x Economy: How to Read the Metrics                                    |
+----------------------------------------------------------------------------------+
| [Block A] GDP vs 2019                                                           |
| Meaning: Current GDP growth compared with pre-pandemic baseline (2019).         |
| Example: United Kingdom = -1.5pp (2023)                                         |
| Interpretation: In 2023, UK GDP growth is 1.5 percentage points lower           |
| than its 2019 baseline growth rate.                                              |
+----------------------------------------------------------------------------------+
| [Block B] Recovery vs 2020                                                      |
| Meaning: Current GDP growth compared with 2020 trough year.                     |
| Example: United Kingdom = +8.9pp (2023)                                         |
| Interpretation: In 2023, UK GDP growth is 8.9 percentage points higher          |
| than its 2020 trough growth rate.                                                |
+----------------------------------------------------------------------------------+
| [What this DOES NOT mean]                                                       |
| - This does NOT prove COVID cases directly caused GDP change.                   |
| - This does NOT represent total GDP size in dollars.                            |
+----------------------------------------------------------------------------------+
| Quick Check                                                                      |
| Q1: Which metric shows pre-pandemic gap?  [_________]                           |
| Q2: Which metric shows post-trough rebound? [_________]                         |
+----------------------------------------------------------------------------------+
```

## Screen 2 — Country-Time Comparison

```text
+----------------------------------------------------------------------------------+
| Compare Countries Across Time                                                    |
+----------------------------------------------------------------------------------+
| Country A [United Kingdom]  Country B [Australia]  T1 (2020)  T2 (2023)         |
+--------------------------------------+-------------------------------------------+
| [Country A Snapshot]                 | [Country B Snapshot]                      |
| Cases:        T1 2.3M  T2 24.0M      | Cases:        T1 28K   T2 11.7M           |
| GDP vs 2019:  T1 -12.0pp T2 -1.5pp   | GDP vs 2019:  T1 -3.7pp T2 -0.3pp         |
| Recovery2020: T1 0.0pp  T2 +8.9pp    | Recovery2020: T1 0.0pp  T2 +3.4pp         |
+--------------------------------------+-------------------------------------------+
| Evidence-Based Conclusion                                                       |
| 1) Which country had deeper shock? [________________________]                   |
| 2) Which value supports your answer? [____________________]                     |
| 3) What cannot be concluded here? [_______________________]                     |
+----------------------------------------------------------------------------------+
| Boundary Reminder: Aligned trends indicate correlation, not automatic causation. |
+----------------------------------------------------------------------------------+
```

## Screen 3 — Trust & Source Transparency

```text
+----------------------------------------------------------------------------------+
| Before You Trust the Conclusion                                                  |
+----------------------------------------------------------------------------------+
| [Source Card]                                                                    |
| - Data sources: World Bank (GDP growth), OWID/WHO (COVID indicators)            |
| - Last updated: Data snapshot 2026-04-27                                         |
| - Missing data note: Case reporting standards vary by country and period;        |
|                      some values may be revised.                                  |
+----------------------------------------------------------------------------------+
| [Method Card]                                                                    |
| - GDP vs 2019 = current-year GDP growth - 2019 GDP growth                        |
| - Recovery vs 2020 = current-year GDP growth - 2020 GDP growth                   |
| - Limitations: cross-country reporting differences; lag in economic stats;       |
|                correlation does not imply causation                               |
+----------------------------------------------------------------------------------+
| [Boundary Banner]                                                                |
| "Observed alignment does NOT prove causation."                                   |
+----------------------------------------------------------------------------------+
| Trust Check                                                                       |
| Trust score (1-5): [ ] [ ] [ ] [ ] [ ]                                           |
| What extra information do you need to trust this?                                |
| [______________________________________________________________________________] |
+----------------------------------------------------------------------------------+
```
