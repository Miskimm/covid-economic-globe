# Summary

## Key insights (n = 10)

1. Several users understood `GDP vs 2019` only after treating 2019 as a visible baseline; the label needs to explicitly explain what `100`, `above`, and `below` mean.
2. `Recovery vs 2020` is more easily confused with health recovery unless labelled as economic recovery from the 2020 trough.
3. Users who prefer the interface do not always understand it better; S03, S05, and S10 show preference-understanding mismatch.
4. Source transparency increases trust for careful users, but some users trust familiar source names without reading limitations.
5. The most serious risk is false causation: some users conclude that high cases directly caused GDP decline.

## Invalidated or weakened assumptions

- "Clear source names are enough for trust": weakened, because some users still did not understand how data was combined.
- "Users will naturally connect health and economy correctly": invalidated, because several users focused only on cases/deaths.
- "Preference indicates comprehension": invalidated, because several high-preference users had low interpretation scores.

## Remaining unknowns

- Whether inline definitions or a guided narrative screen improves understanding more.
- Whether users perform better with a dashboard than a globe-style interface.
- Whether a larger or more diverse sample from ECON, and DECO backgrounds would change the misreading rates reported in this round (n = 10).

## Suggested next design direction

Prioritise a guided comparison dashboard or narrative evidence flow with clearer metric definitions, visible baseline explanations, source/method notes, and explicit "correlation not causation" prompts.
