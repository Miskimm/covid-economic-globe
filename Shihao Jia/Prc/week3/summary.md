# WEEK3 讨论总结（DECO7180 Tutorial）

本次课程围绕第一次评估前的 problem framing 展开，核心目标是把“模糊兴趣”转化为“可研究、可论证、可执行”的问题空间。导师强调：这周不是开始做方案，而是通过系统研究确认你为什么要做、在什么边界内做、为谁做。

## 1. 问题框定（Problem Framing）的核心要求

- 问题定义需要迭代，不是一次写完；每轮研究都应推动问题更清晰。  
- 研究问题应避免过宽（难落地）或过窄（缺乏价值），要保持可探索性与可执行性平衡。  
- 团队需要明确问题边界、受影响人群、场景条件与潜在限制。  
- 报告重点应放在“为什么这个问题值得研究”，而非“我想做什么功能”。  

## 2. 二手研究方法与学术资源使用

- 课程强调二手研究是当前阶段主轴，用于建立领域基础知识与证据链。  
- 推荐来源包括 ACM Digital Library、UQ Library、Google Scholar。  
- 不仅要“找到文献”，还要判断文献与研究问题的相关度、可信度与贡献度。  
- 可借助 Zotero 等工具管理文献与引用，避免后续证据链断裂。  

## 3. 案例讨论：基建腐败与吹哨议题

- 课堂通过基建数据与历史案例讨论，强调“看见数据”不等于“理解问题”。  
- 研究者需补充政策、历史、利益结构等背景，才能形成有深度的问题认识。  
- 讨论特别指出该类议题存在伦理和现实风险，研究设计需考虑潜在影响。  
- 强调识别利益相关者（公众、机构、从业者、监管方）是问题框定的关键。  

## 4. 团队协作与课堂共创

- 同学在小组内分享个人研究问题，再映射到团队方向进行整合。  
- 通过同伴反馈优化研究问题表述，使其更具体、更可验证。  
- 每组需选代表向全班回报问题方向与讨论要点，接受进一步挑战与修正。  
- 下周 studio 时间将主要用于推进报告，不再依赖大量讲授。  

## 5. 后续行动项（Action Items）

1. 完成并提交 problem-framing 报告，说明研究过程、关键发现、边界与限制。  
2. 补充高质量二手研究文献，并明确每篇文献如何支持团队问题定义。  
3. 在小组内继续迭代研究问题，确保问题可被后续调研和设计决策支撑。  
4. 如遇问题及时向导师咨询，避免方向偏离到提交前才修正。  

## 6. 总结

本周主线是：**先把问题研究清楚，再谈设计介入**。课程要求团队以证据驱动问题框定，通过学术与背景研究建立可辩护的项目基础，为后续研究设计与原型工作打底。
